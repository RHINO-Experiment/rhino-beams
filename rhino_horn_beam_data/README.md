RHINO pyramidal horn beams
--------------------------

This directory contains several .zip files with the CST beam 
output files for the RHINO horn antenna with different boundary 
conditions and assumptions about the ground.

Each .zip file contains text files numbered according to the 
frequency in MHz. Each file contains the following columns:

 -  (0) Theta [deg.]
 - (1) Phi   [deg.]
 - (2) Abs(Dir.)[dBi]
 - (3) Abs(Theta)[dBi]
 - (4) Phase(Theta)[deg.]
 - (5) Abs(Phi)[dBi]
 - (6) Phase(Phi)[deg.]
 - (7) Ax.Ratio[dB]
