# 3D scans of the Green at JBO

_2026-07-09_

The .pts files contain 3D scanner point clouds generated by 
William Vyner-Brooks and Conrad Szyman at Jodrell Bank 
Observatory on the week commencing 6th July 2026.

You can use software like CloudCompare to visualise these files.
