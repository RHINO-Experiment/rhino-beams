RHINO pyramidal horn $S_{11}$
-----------------------------

This directory contains several .txt files with the CST beam 
output files for the RHINO horn antenna $S_{11}$ with different boundary 
conditions and assumptions about the ground.

Each file contains the following collumns:
 - (0) Frequnecy [GHz]
 - (1) $|S_{11}|$ [dB]
